# Правила набора Loodsman-Skill

Общие правила — соседний скилл skill-skill (`knowledge/00_ПРАВИЛА.md` там).

## Что умеет набор

Скриптовая работа с ЛОЦМАН:PLM 2014 (АСКОН) **только на чтение**:
обход дерева проекта, список документов и файлов, выгрузка файлов
без взятия в работу, контроль версий по CRC, индекс с гиперссылками
`ask:Loodsman.URL`.

## Чего набор не делает

Никаких записей в базу: без CheckOut, CheckIn, Up*, New*, Kill*.
Даже читающие методы вызываются только из белого списка `Get*` /
`ConnectToDB` (10-02). Методы `RunMethod` с неизвестной сигнатурой
на живом клиенте не подбирать (30-05).

## Канал доступа

Официальный COM `DataProvider.LoodsmanConnection` → `API8` →
`GetSimpleAPI` → `RunMethod`/`GetDataSet` (10-01). Клиент ЛОЦМАН при
работе не нужен и не запускается (inproc DLL); нужен только доступ
к серверу приложений. Прямой SQL не используется: база под обычной
учёткой Windows видна пустой (30-04).

## Настройки

Все данные конкретной установки (имя базы, имена типов связей,
пути) — в `local/` (не под git): формат и поля описаны в 40-01.
В коде и `SKILL.md` их нет.

## Язык кода

`loodsman_export.vbs` — только ASCII-литералы: русские имена базы и
связей читаются из ini (30-01). Python-скрипты — UTF-8.
