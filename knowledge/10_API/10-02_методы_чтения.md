# Белый список методов чтения

Вызывать только эти имена. Всё остальное (`Up*`, `New*`, `Kill*`, `Check*`,
`Del*`, `Insert*`, `Update*`, `Sign*`, `Grant*`, `Exec*`) — запись/риск.

## Состав и дерево

| Метод | Параметры | Возвращает |
|---|---|---|
| `GetLinkedFast2` | `(idVersion, типСвязи, inverse)` | дети объекта по связи: `_ID_LINK, _ID_VERSION, _ID_TYPE, _PRODUCT, _VERSION, _ID_STATE, _DOCUMENT, _MIN_QUANTITY, _MAX_QUANTITY, _ACCESSLEVEL, _LABEL, _LABEL_NAME, _ID_LOCK` |
| `GetTree` | `(тип, изделие, версия, idVersion, типСвязи, withAttrs)` | то же + `_STATE, _LINKTYPE, _HAS_LINK, _LOCKED` |
| `GetFullTree` | `(списокId:строка, params)` | полное поддерево (не проверено) |
| `GetProjectList` | `()` | корневые папки дерева проектов |
| `GetVersionList` | `(тип, изделие)` | список версий объекта |

Связи и состав: у объекта два рабочих типа связи — **состав** (имя вида
`Состоит из ...`, у каждой базы своё) и **документы** (имя вида `Документы`).
Полный список типов связей объекта — `GetLinkList(idVersion)` →
`_ID, _NAME, _INVERSENAME`.

## Карточка, поиск и атрибуты

- `FindObjects(тип, изделие, версия, состояние, услАтрибутов, проекты, связь)` —
  поиск; проверено: пустые строки кроме изделия с маской `%текст%` ищут
  по всем типам → `_ID_VERSION, _TYPE, _DOCUMENT, _STATE, _PRODUCT,
  _VERSION, _REVISION, _HAS_LINK, ...`
- `GetVersionList(тип, изделие)` — все версии точного объекта:
  `_ID_VERSION, _DATEOFCREATE, _STATE, _OWNER, ...`
- `GetTree` c `boWithAttrs=True` отдаёт атрибуты объектов прямо в наборе
  (колонки-атрибуты: «Наименование», «Примечание», ...) — имена колонок
  зависят от базы, задаются в local/loodsman.ini (objNameAttr/objNoteAttr).
- `GetInfoAboutVersion(тип, изделие, версия, idVersion, режим)` — режим:
  `2` = атрибуты, `3` = атрибуты+системные, **`7` = список файлов**.
  0 — «Неизвестный режим работы метода»; полный перечень режимов в
  открытых источниках не найден — не подбирать на рабочей базе (30-05).
- `GetAttributesValues2(списокId, списокАтрибутов, "")` — пакетные
  атрибуты (проверено: отрабатывает; поля `_ID_VERSION, _ID, _NAME, _VALUE`).

## Файлы

- `GetFileById(idДокумента, имяФайла, "")` → **путь к файлу** на файловом
  сервере (файл при этом не берётся в работу). Дальше — обычное копирование
  по SMB. Ошибка «файл не сохранен в базе» — у записи файла нет тела (30-03).
- `GetInfoAboutVersionsFiles(списокId:строка)` — файлы нескольких версий
  одним запросом (проверить формат списка на копии).

## Датасет (IDataSet)

`First/Last/Next/Prior`, `Eof/Bof`, `RecordCount`, `FieldCount`,
`FieldName(i)`, `FieldValue(имя)`. Поля у каждого метода свои — читать
динамически по `FieldCount/FieldName`, не полагаться на константы.
